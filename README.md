# 고려 역사 인물 탐험 | 교과서 활동 자료 3 연계판

초등학교 5학년 교과서 55쪽 **「활동 자료 3: 고려 역사 인물 붙임 딱지, 카드」**와 함께 사용하는 인물 조사 웹페이지입니다.

## 구성

- 왕건, 광종, 서희, 양규, 강감찬, 김윤후 총 6명의 선택 카드
- 교과서 활동 자료 3(사용자 제공 PDF)의 인물 일러스트를 **6명 모두** 활용
- 인물별 주요 활동과 업적 **4개**, 배경 설명, 어려운 낱말, 탐구 질문
- 학생이 스스로 문장을 만들 수 있도록 **한 줄 정리 예시와 복사 기능 제거**
- 나눔스퀘어라운드 글꼴, 모바일/태블릿/PC 반응형 지원

## 교과서 카드와 연계하는 방법

1. 첫 번째 PDF 페이지에서 관심 있는 인물의 붙임 딱지를 고릅니다.
2. 해당 인물의 웹페이지를 열어 역사적 상황과 업적을 조사합니다.
3. 두 번째 PDF 페이지의 카드에 인물 그림을 붙입니다.
4. ‘업적’ 칸에는 **무엇을 했는지, 어떤 결과가 있었는지**를 자기 말로 정리합니다.

## 사이트 실행

`index.html`과 `images/` 폴더를 같은 위치에 둔 채로 `index.html`을 브라우저에서 열면 바로 실행됩니다. 웹폰트와 상세 역사 자료 링크는 인터넷이 연결되어 있을 때 이용할 수 있습니다.

## GitHub Pages 배포

1. 압축을 풀고 `index.html`, `images/` 폴더, `README.md`를 저장소 최상위에 업로드합니다.
2. GitHub 저장소의 `Settings → Pages`를 엽니다.
3. `Deploy from a branch`, `main`, `/(root)`로 설정한 뒤 저장합니다.
4. 만들어진 주소를 학생들에게 안내합니다.

인물별 주소는 `#/person/wanggeon`, `#/person/yanggyu`와 같은 형식이어서 GitHub Pages에서 새로고침해도 화면을 유지합니다.

## 수정 방법

`index.html`의 하단 `const PEOPLE` 데이터에서 인물 소개·업적·질문을 편집할 수 있습니다. 그림은 `images/` 폴더에서 동명 PNG 파일로 교체할 수 있습니다.

- 인물 **그림 출처**: 사용자가 제공한 교과서 활동 자료 PDF 1쪽, 활동 자료 3. 그림은 인물의 실제 모습을 기록한 초상화가 아닌 학습용 일러스트입니다.
